# Interview Prep Notebook

A local study site for JavaScript, React, and React Native interview answers — from basics to advanced.

## Folder structure

```
Interview/
├── index.html              # App shell
├── package.json
├── src/
│   ├── css/styles.css      # Layout and theme
│   ├── js/app.js           # Search, filters, add/edit answers
│   └── data/               # Built-in Q&A (edit these to add more seed answers)
│       ├── index.js
│       ├── javascript.js
│       ├── react.js
│       └── react-native.js
```

## Run

```bash
npm start
```

Then open http://localhost:3000

Your own answers are stored in the browser (localStorage). Use **Export notes** to save a backup JSON file.
